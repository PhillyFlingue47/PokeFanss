# Exercice - Git collaboratif
Réaliser un site web fan sur l'univers pokemon
## Pages web à créer
- Accueil
- Listing des produits multimédia (Jeux, animés, ...)
- Les personnages importants
- Détail pour chaque personnages
- Un mini pokedex (30 pokemons max)
- Liste des villes dans l'animée
- Détail pour chaque villes
- Formulaire de contact
## Contraintes
Créer un seul projet et vous devez collaboré dessus en utilisant git.  
L'application web doit être uniquement réaliser en html et en css (pas de JS/TS :p).  
### Git
- Utiliser une convention pour les nom de commit et de branche.
- Les pull request doivent être relu avant leur fusion.  
- La branches `main`/`dev` doit être protege.
- La modification de la branche `main` doit être réaliser par pull request. 
### Design
- L'application doit avec un layout cohérent entre chaque page.
- Le site doit respecter les régles d'accessibilités
- Faire un miminum de CSS (cc Shirley)
